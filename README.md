# 🏭 AI Smart Industrial System

AI Smart Industrial System adalah platform monitoring industri modern berbasis AI yang dilengkapi dengan:

- 🔥 Realtime Sensor Monitoring
- 🎥 AI CCTV Detection
- 🛰 3D Digital Twin Factory
- 📊 Analytics Dashboard
- 📄 Export Excel & PDF Report
- 🤖 AI Chatbot Operator
- ⚠ Smart Industrial Alert System

---

# 🚀 Features

## ✅ Realtime Sensor Monitoring
Monitoring:
- Temperature
- Humidity
- Gas Sensor
- Machine Status

---

## 🎥 AI CCTV Detection
Menggunakan:
- OpenCV
- YOLO AI Detection
- Live Camera Streaming Flask

Deteksi:
- Person
- Smoke
- Dangerous Activity

# ⚙ Installation

## 1. Clone Repository

```bash
git clone https://github.com/Haikal412006/AI-Smart-Industrial-System.git
```

---

## 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## 3. Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 4. AI CCTV Setup

```bash
cd ai-cctv
pip install -r requirements.txt
python detect.py
```
